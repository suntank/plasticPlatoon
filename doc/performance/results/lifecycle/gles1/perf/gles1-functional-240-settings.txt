All *_ms except gpu_ms are CPU-side wall times.
gpu_ms is optional asynchronous GPU work for gpu_origin_serial, which can be a preceding view; -1 means unavailable.
Deduplicate GPU origin serials and associate them with renderer_serial; do not add a delayed result to the current frame.
frame_ms is completion-to-completion for the entire display, including frame limiting. First row has no interval.
server_ms includes simulation + snapshot/send; submit_ms includes visibility and model work. Do not add nested columns.
rss_kib is process resident memory sampled every 60 frames on Linux; -1 means unavailable.
monsters/dead_monsters use server flags; projectiles_by_effect is an estimate, not a gameplay entity census.
r_perf counters exclude 2D/HUD. Unsupported renderer counters are -1 in per-view CSV.
