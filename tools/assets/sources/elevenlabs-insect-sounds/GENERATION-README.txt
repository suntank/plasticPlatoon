Plastic Platoon | Ant and Spider Sound Options

18 original ElevenLabs effects: two takes for each of nine sound categories.
Ant: sight alert, pain, attack, idle and combat scuttle.
Spider: pain, attack, idle and combat scuttle. Spider sight is intentionally silent.

FILES
raw/ contains original 48 kHz stereo 16-bit WAV downloads.
game_ready/ contains 48 kHz mono 16-bit PCM WAV copies for engine import.
No gain changes, trimming, fading, pitch changes or timing shifts were applied.
Each folder uses sight_01.wav / sight_02.wav, pain_01.wav / pain_02.wav, etc.
The audition reel follows the cue list below with one-second gaps. It uses the mono versions with their original levels.

INTENDED SOUND DIRECTION
Ant sounds emphasize sharper insect screeches, dry mandible clicks and chitin rasp.
Spider sounds emphasize restrained hiss, tiny fang clicks, hairy leg brushes and lighter scuttling.
These are original insect-like designs, not copies of Half-Life 2 recordings.

TIMING AND TESTING
The requested generation lengths were 1.0s sight, 0.5s pain, 0.8s attack and 1.2s idle/scuttle.
Measured WAV durations are 1.0s for sight, 0.4865s for pain, 0.8065s for attack and 1.2s for idle/scuttle.
The shortest reliable explicit UI setting was 0.5s. An initial spider-pain attempt returned 2s on Auto and was replaced; that unused attempt remains only in ElevenLabs history.
Attack prompts request the bite in the middle of the 0.8s clip to suit the 0.4s attack-frame timing. Actual audible bite placement has not been verified and no timing edits were guessed.
Scuttle clips are short gait-cycle bursts, not individual footsteps and not seamless loops. Use restrained cadence rather than firing the complete burst on every footfall.
These files were checked for valid decoding, sample format, duration, distinct contents and nonzero signal. I could not listen to the rendered audio in this workflow or play-test it in the game. Please audition the takes and check the bite timing and mix before choosing them.
No game code or installed assets were changed by producing this pack.
